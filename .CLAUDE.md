## Team conventions
- IDs: REQ-### (requirements), TASK-### (micro-tasks). Every TASK links ≥1 REQ.
- Micro-task = one PR-sized change, ≤ ~200 LOC, ≤ 5 files, independently testable.
- Task list naming: "TASK-012 IMPL", "TASK-012 TEST", "TASK-012 REVIEW".
- File ownership: only edit files inside your role's ownership area (see your role brief).
  If you need a change elsewhere, message the owner.
- A task's REVIEW task is completed only with verdict APPROVED; TEST only with PASS.
- Write durable output to work/ (plans, reports), not only in messages.
