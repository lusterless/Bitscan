## Files
- `web/src/api/schema.d.ts`: generated by `npm run gen:api` from the current `manager/openapi.json`. Not edited by hand.
- `web/src/api/client.ts` (about 10 hand-written lines): `baseUrl: ""` is unchanged. The comment now records the recheck. A **type-only** guard was added (no runtime code):
  ```ts
  type HealthPath = "/healthz" | "/readyz";
  type AssertTrue<T extends true> = T;
  export type UserPathsArePrefixed = AssertTrue<
    [Exclude<keyof paths, HealthPath>] extends [`/api/v1/${string}`] ? true : false
  >;
  ```
  If a later path (for example the M3 metrics route) is added without the `/api/v1/` prefix and is not added to `HealthPath`, `npm run typecheck` fails here with TS2344. That forces the next `baseUrl` recheck.

No dependency added; `package.json` and `package-lock.json` untouched.
