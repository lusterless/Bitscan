
## Notes for the tester

- The G42 bundle check itself (the script that fails on a planted inline `<script>`, `<style>`, `style=` or `https://` link) is a CI step in TASK-127 (impl-deploy), not part of this task. CHK-M5-350 plants an inline `<script>` in `web/index.html`; with this config Vite keeps an inline script inline in the output, so the plant shows up in the built `index.html`.
- `emptyOutDir: true` clears `manager/bitscan_manager/webui/` before each build. The folder only ever holds build output; the TASK-112 fixture build folder is the tester's and lives elsewhere.
- The Vitest environment is now jsdom for every test file (the existing `client.test.ts` still passes).
- The browser requests `/favicon.ico` on its own; it gets the manager's normal 404. No icon link was added, because a `data:` icon would break G42 and the CSP.
