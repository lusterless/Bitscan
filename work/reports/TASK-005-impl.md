## ESLint guards
- **Inline config is off** (finding 1): `linterOptions: { noInlineConfig: true, reportUnusedDisableDirectives: "error" }` for every file. An `eslint-disable` comment is ignored, so the guard still reports its error. The comment itself also produces a warning, which `--max-warnings 0` makes fatal.
- **Globs** (finding 4): guards apply to `src/**/*.{ts,tsx,mts,cts,js,jsx,mjs,cjs}`. The network exemption is the single file `src/api/client.ts` (revision 3). JSX parsing is on for `.js` and `.jsx`.
- **Static keys:** each property guard matches `a.b`, `a["b"]` and a template literal with no substitutions, e.g. ``a[`b`]`` (finding 2). Destructuring keys (`{ b }`, `{ "b": x }`, ``{ [`b`]: x }``) are matched where listed.
- **Plain text (TS §6.3):**
  - JSX `dangerouslySetInnerHTML`, and the same object key;
  - assigning `innerHTML` or `outerHTML` (`=` and `+=`);
  - any `insertAdjacentHTML` member;
  - `write` and `writeln` on `document`, on `x.document` (e.g. `window.document.write`), and destructured from `document` (finding 3).
- **Token in memory only (TS §8.1):**
  - any identifier `localStorage`, `sessionStorage` or `cookieStore`;
  - any member or destructured key `localStorage`, `sessionStorage`, `cookieStore` or `cookie`, which covers `const { cookie } = document` (finding 3).
- **Built keys** (main's request on finding 2): a computed member key or destructuring key that is a `+` concatenation containing a string or template literal, or a template literal with substitutions, is an error, whatever the name. Examples: `window["local" + "Storage"]`, ``window[`local${"Storage"}`]``. `a[i + 1]` and `m[k]` stay allowed.
- **Generated client only (web-ui.md line 10):** any identifier `fetch` or `XMLHttpRequest`, and any member or destructured key with those names, in every file under `src/` except `src/api/client.ts`. That includes `src/api/schema.d.ts` and any other file in `src/api/`. `client.ts` keeps all the other guards.

## Not covered by lint (left to code review)
- Keys hidden behind a variable or a call, e.g. `const k = "localStorage"; window[k]`, `"local".concat("Storage")`, `Reflect.get(window, k)`, `Object.assign(el, { innerHTML })`.
- Aliasing the global object or `document`, e.g. `const d = document; d.write(s)`.
- Review nit 5 sinks outside REQ-014: `srcdoc`, `setHTMLUnsafe`, `createContextualFragment`, `DOMParser`, `indexedDB`, `WebSocket`, `EventSource`, `sendBeacon`, `eval` and `new Function`. The CSP `'self'` with no `'unsafe-eval'` (TS §6.3) blocks eval at runtime.
