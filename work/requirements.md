## M3 agent API and scheduler (inventory only)

Scope, from the lead's M3 request (2026-10-22) and the milestone reorder and carry-over rows (`work/decisions.md`, 2026-10-20; M2 rows 2026-10-21 and 2026-10-22):
- the six TS §6.1 agent routes on their own router and token check; the results route answers 409 for every post, because no compliance job exists before M9;
- the TS §6.5 wire contract, including the full compliance Job and Results schemas, frozen in `manager/openapi.json` now, with request and response fixtures shared with the M4 Go agent;
- enrolment tokens, enrolment, approval and rejection, the agent token check, token rotation;
- heartbeat, job pull (inventory jobs only), inventory upload and ingestion, inventory queueing and `offline_sweep`;
- user routes `/enrollment-tokens`, `/enrollment-requests` (list, approve, reject), `GET /agents`, `/agents/{id}`, `/agents/{id}/packages`, `PUT /agents/{id}/tags`, `POST /agents/{id}/revoke`, `GET` and `PATCH /settings`, `GET /audit-log` (moved from M2, decisions 2026-10-21) and the metrics route;
- the M3 alerts and metrics of TS §8.4, including the clock-skew alert (M2 carry-over);
- carry-overs: body caps on templated agent routes, the metrics route versus `HealthPath`, OpenAPI paths with the full `/api/v1` prefix and the web client regenerated at the end, OpenTelemetry rechecked after new app wiring.

Not in M3: package search and CSV, and the UI (M5); the Go agent and `.deb` (M4); importer, evaluator, scans, compliance job building, result intake and the runner (M7 to M11); retention (M11), including the 30-day inventory-job, 180-day snapshot, 90-day decided-request and unreferenced-package rules; `GET /agents/{id}/scans` (M9: it lists scans, none exist before M9, and its item shape is the `GET /scans` item); the load and end-to-end tests (M6); a CLI command that creates `bse_` tokens (`work/decisions.md` 2026-10-20, "Not to be added"); anything in the CLAUDE.md out-of-scope list.

The canary sweep also plants `bsa_` and `bse_` tokens, inventory package names and results stdout and stderr. "Alert entry" means one `audit_log` row with `detail.alert = true` and the #71 kind.
